解压后把三个文件放进游戏目录的 `mods\Wizard\`：

```
Slay the Spire 2\mods\Wizard\
├── Wizard.dll
├── Wizard.json
```

同时需要 `mods\BaseLib\`（创意工坊订阅即可，要求 **≥ 3.4.8**）。

**本版（v0.6.2）：重做燃烧机制 + 平衡性调整**

- **重做燃烧机制**
  - 燃烧现在造成的是 **[b]无来源火焰伤害[/b]**：不再是不受任何加成的固定伤害，
    而是会受到目标身上的「易伤」「寒冷」等效果影响；
  - 同时仍然无视格挡、不加力量，也不会触发"你造成伤害时"的效果；
  - 血条上的燃烧预测段会按**实际会掉的血**实时更新（目标获得/失去易伤、寒冷时立即变化）。
- **被消耗时有效果的牌**（「尾注」「心流」）现在会在「选择消耗的卡牌」界面里**金边亮起**。
- **平衡性调整**
  - 永恒回响：费用 1 → 2（1）；升级不再给予「保留」，改为降低费用。
  - 纵火狂：每次给予燃烧获得的活力 4（6） → 6（8）。
  - 交流电：稀有度 稀有 → 罕见。
  - 回忆：费用 1（0） → 0；弹回张数 2 → 1（2）。
  - 修行：费用 2（1） → 1；新增「虚无」，升级改为移除「虚无」。
  - 伟大法袍：稀有度 罕见 → 稀有。

Wizard — a character mod for **Slay the Spire 2**.

Extract the three files into `Slay the Spire 2\mods\Wizard\`. Requires **BaseLib ≥ 3.4.8**.

**This version (v0.6.2): Burn rework + balance**

- **Burn reworked**
  - Burn now deals **[b]source-less Fire damage[/b]**: instead of fixed damage unaffected by
    everything, it is now affected by the target's Vulnerable, Chill and other modifiers;
  - It still ignores Block, does not gain Strength, and does not trigger
    "whenever you deal damage" effects;
  - The burn segment on the health bar now previews the **actual damage** in real time.
- **Cards with effects that trigger when Exhausted** (Endnote, Mind Flow) now **glow gold**
  while a "choose cards to Exhaust" prompt is shown.
- **Balance**
  - Eternal Echo: cost 1 → 2(1); upgrading no longer grants Retain, it now reduces cost.
  - Pyromaniac: Vigor per Burn application 4(6) → 6(8).
  - Alternating Current: rarity Rare → Uncommon.
  - Recollection: cost 1(0) → 0; cards returned 2 → 1(2).
  - Asceticism: cost 2(1) → 1; now Ethereal, upgrading removes Ethereal.
  - Magus Robe: rarity Uncommon → Rare.

85 cards / 37 powers / 10 relics / 3 potions / 4 special events / 1 special monster /
full dialogue for all 9 Ancients.
