《杀戮尖塔 2》巫师角色 mod —— 构建产物存档。

解压后把三个文件放进游戏目录的 `mods\Wizard\`：

```
Slay the Spire 2\mods\Wizard\
├── Wizard.dll
├── Wizard.json
└── Wizard.pck
```

同时需要 `mods\BaseLib\`（创意工坊订阅即可，要求 **≥ 3.4.7**）。

> 推荐走创意工坊安装，会自动更新：
> https://steamcommunity.com/sharedfiles/filedetails/?id=3807136195

**内容量**：65 张卡牌 / 29 个能力 / 9 个遗物 / 3 瓶药水 / **3 个特殊事件** /
**1 个特殊怪物** / 9 位先古之民完整对话。三系法术：火焰、雷电、寒冰。简体中文 + English。

**本版（v0.4.3）**

- 新增卡牌「启示」：0 费，罕见技能。
  从 3 张随机（升级过的）其他颜色的技能牌中选择 1 张加入你的手牌。消耗。

  选项上直接写明会拿到哪件遗物。
- 「启示」与「暗黑神秘学」升级后的「升级过的」文案加了金色强调，与原版一致。

Wizard — a character mod for **Slay the Spire 2**.

Extract the three files into `Slay the Spire 2\mods\Wizard\`. Requires **BaseLib ≥ 3.4.7**.

**This version (v0.4.3)**

- New card **Inspiration**: 0 cost, Uncommon Skill.
  Choose 1 of 3 random upgraded Skill cards of other colors to add into your Hand. Exhaust.
- New event **Level Secret**: any act.
  Three options, each granting a relic (Common / Uncommon / Rare). Relics are drawn
  from your character's own relic pool first and only fall back to the shared pool
  once that is exhausted; each option names the relic it will give.
- The "upgraded" wording on Inspiration and Dark Mysticism is now highlighted in gold,
  matching the base game.

65 cards / 29 powers / 9 relics / 3 potions / 3 special events / 1 special monster /
full dialogue for all 9 Ancients. Three spell schools: Fire, Lightning, Ice.
Chinese + English text.

Source: https://github.com/Traumere7/sts2mod-wizard
