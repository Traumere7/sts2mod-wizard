# 繁體中文（zht）本地化規範

## 1. 硬性格式

- key 與 eng 完全一致；JSON UTF-8、2 空格縮排、無尾逗號。
- BBCode 標籤「類型 + 對數」鏡像英文；不自行加色/減色。
- 佔位符根名保留；`:diff()`、`:energyIcons()`、`:percentMore()`、`:percentLess()`、`{IfUpgraded:show:…}`、`{InCombat:…}`、`{energyPrefix:energyIcons(1)}` 不改寫。
- 中文沒有複數：刪掉 `:plural:`，保留根變數。必要時用 `{Amount:choose:…|…}`，但多數不需要。
- `\n` 段落與英文一致。

## 2. 空格

- **數字與佔位符兩側加半形空格**：
  - `造成 {Damage:diff()} 點傷害。`
  - `獲得 [blue]{Amount}[/blue] 層[gold]虛弱[/gold]。`
  - `第 [blue]{Turn}[/blue] 回合`
  - `接下來 {Amount} 個回合`
- **標籤內、標籤與中文之間不加空格**：
  - 正確：`獲得 {Block:diff()} 點[gold]格擋[/gold]。`
  - 錯誤：`[gold] 格擋 [/gold]`
- 句末標點前不加空格。
- `1{energyPrefix:energyIcons(1)}` 這類「數字 + 能量圖示」不加空格（照 zhs/原版卡牌）。
- 卡牌正文的數值**不加 `[blue]`**；只有遺物、能力 smartDescription、事件選項才用 `[blue]` 包數字。

## 3. 標點與符號

- 全形：，。！？、；：（）「」『』
- 刪節號：`……`
- 破折號：`——`
- 引號：`「」`；嵌套 `『』`
- 並列用「與」或「、」，不用英文 `&`、`/`。

## 4. 數字與量詞

- 遊戲數值用阿拉伯數字：`抽 2 張牌`、`失去 3 點生命`。
- 散文/風味可用中文數字：`只要一頁`、`敲了三下`、`數頁`。
- 量詞：
  - 牌：張
  - 遺物：件
  - 藥水：瓶
  - 敵人：名
  - 回合：個
  - 次：次
  - 層數：層
  - 格擋 / 生命 / 能量：點
  - 金幣：枚

## 5. 固定用詞（與 zhs 不同）

| 概念 | zht | 不要用 |
|---|---|---|
| next turn | **下回合** | 下個回合 |
| heal | **恢復** | 回復 |
| transform | **轉化** | 變化 |
| exhaust pile | **消耗堆** | 消耗牌堆 |
| plating | **鍍甲** | 覆甲 |
| intangible | **無形** | 無實體 |
| debuff | **弱化效果** | 負面效果 |
| skip | **略過** | 跳過 |
| deck | 牌組 | 牌组 |
| mod | 模組 | 模块 |
| restart | 重新啟動 | 重启 |

字形：`裡`、`著`、`為`、`祕`（神祕/祕密）、`妳` 不用（一律 `你`）、`牠` 不用（用 `它` 或 `其`）。

## 6. 句法

- 多短句，主語可省略。
- 條件句：`若……，則……`、`若……，就……`。
- 時點：`在你的回合開始時`、`在你的回合結束時`、`戰鬥開始時`、`戰鬥結束時`。
- 頻率：`每當你……時`、`每回合限 1 次`。
- 對象：`對所有敵人`、`對一名隨機敵人`、`對自己`。
- 因果/代價：`以……為代價`、`換取……`。

## 7. 卡名風格

- 目標 2–4 字為主；可用 5 字（如 `暗黑神祕學`）。
- 法術牌可用「術」：火球術、烈焰術、治療術。
- 武技可用「拳」：烈焰拳。
- 避免整批照搬 zhs 的 4 字網文腔；保持原版 zht 的克制與文學感。
- 與原版撞名時改名（見 `GLOSSARY.md`）。

## 8. 事件/對話

- 敘事用 `你`，現在時/完成時依語感；不用 `您`。
- 引號 `「」`；內心獨白可用 `——`。
- 先古對話依 `VOICE.md` 的語氣；舞臺說明用 `[i][font_size=22]…[/font_size][/i]`，句末不加空格。
- NEOW 用大量 `……` 與停頓；OROBAS 短句 + `！！`；PAEL 用 `[thinky_dots]`。
