# 角色与先古语气表

> 写 `characters.json` / `ancients.json` 前先看这一份。
> 例句只示范语域，不是最终定稿。

## Wizard

- **zht**：我／你；短句、陈述、略古风、不客气。
  - 「我不需要好看。我只需要有用。」
  - 「你把我拉回來，是想讓我再試一次，還是想看我怎麼死？」
- **jpn**：私／お前；だ・である；短句；不用敬语。
  - 「美しくなる必要はない。役に立てばいい。」
  - 「私を引き戻したのは、もう一度挑ませるためか？ それとも、私が死ぬ様を見るためか？」
