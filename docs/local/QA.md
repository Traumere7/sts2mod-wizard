# 本地化自检清单

每个文件落盘后逐项过一遍。

## 结构

- [ ] JSON 可解析；2 空格缩进；无尾逗号；UTF-8。
- [ ] key 集合与 `eng` 完全一致（无多、无少、无改名）。
- [ ] `\n` 段落数与英文一致；没有把两段并成一段。

## 标签

- [ ] 每种 BBCode 标签的**对数**与英文一致。
- [ ] 嵌套顺序一致（如 `[sine][purple]…[/purple][/sine]`）。
- [ ] 没有因为“想强调”而新增 `[gold]` / `[blue]`。
- [ ] 卡牌正文没有多余 `[blue]` 数字。

## 占位符

- [ ] 每个 `{Root}` 都保留。
- [ ] `:diff()` / `:energyIcons()` / `:percentMore()` / `:percentLess()` 未被改成固定数字。
- [ ] `{IfUpgraded:show:…|…}` / `{InCombat:…|}` 两个分支都译了。
- [ ] `{energyPrefix:energyIcons(1)}` 原样保留。
- [ ] 中文/日文没有 `:plural:` 残留。

## 语言

- [ ] zht：数字/占位符两侧有空格；标签内无空格；全形标点；`下回合`/`恢復`/`轉化`/`消耗堆`/`鍍甲`/`無形`/`弱化效果`/`略過`。
- [ ] jpn：规则文无空格；叙事文句末有空格；语序/量词正确；`廃棄`/`山札`/`捨て札`/`廃棄札`/`手札`/`ブロック`/`エナジー`；不用「層」「點」。
- [ ] 专有名词与 `GLOSSARY.md` 一致。
- [ ] 语气与 `VOICE.md` 一致。

## 命名

- [ ] 卡名/遗物名/能力名/事件名没有与原版已有标题完全撞名。
- [ ] 基础牌 `Strike` / `Defend` 与基础游戏一致。
- [ ] `Burn` 牌（状态牌）与 `Burn` 能力（Power）译名已区分。

- [ ] 随机抽 5 条，与英文对照标签/占位符是否一致。
