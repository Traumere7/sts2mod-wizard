# 日本語（jpn）本地化規範

## 1. 硬性格式

- key 與 eng 完全一致；JSON UTF-8、2 空格縮排、無尾逗號。
- BBCode 標籤「類型 + 對數」鏡像英文。
- 佔位符根名保留；`:diff()`、`:energyIcons()`、`:percentMore()`、`:percentLess()`、`{IfUpgraded:show:…}`、`{InCombat:…}`、`{energyPrefix:energyIcons(1)}` 不改寫。
- 日文沒有複數/數量屈折：刪掉 `:plural:`，保留根變數。
- `\n` 段落與英文一致。

## 2. 空格

- **規則文（卡牌/能力/遺物/藥水）完全不加空格**：
  - `{Block:diff()}[gold]ブロック[/gold]を得る。`
  - `カードを{Cards:diff()}枚引く。`
- **敘事/對話（事件/先古）在 `。！？……` 後加半角空格**：
  - `あなたは足を踏み入れた。 そこには……`
  - NEOW/PAEL 的 `[sine]` / `[thinky_dots]` 內保留 `…… ` 的間隔。
- 標籤內、標籤與日文之間不加空格。

## 3. 標點與符號

- 全形：、。！？「」『』
- 卡牌內 `( )` 用半角；UI/設定/散文用全角 `（）`。
- 刪節號：`……`
- 破折號：`――`（不是 `——`）
- 多詞片假名用 `・`：マグヌム・オプス、トリア・プリマ。

## 4. 語序與量詞（最容易錯）

| 句型 | 寫法 |
|---|---|
| 傷害 | `Xダメージ` |
| ブロック | `X[gold]ブロック[/gold]` |
| HP | `HPをX回復` / `HPをX失う` |
| カード | `カードをX枚引く` |
| 筋力/敏捷/活力/プレート/霊体/魔法威力 | `[gold]筋力[/gold]X` / `[purple]魔法威力[/purple]X` |
| デバフ | `[gold]弱体[/gold]Xを付与する` |
| ターン | `Xターン` |
| 回数 | `X回` |
| 敵 | `敵1体` |

- **不用「層」，不用「點」。**
- 量詞：カード 枚、レリック 個、ポーション 個、敵 体、ターン ターン、回 回。

## 6. 固定動詞搭配

- ダメージを**与える**
- デバフを**付与する**
- ブロック/筋力/敏捷/活力/プレート/霊体/魔法威力/エナジーを**得る**
- HPを**失う** / HPを**回復する**
- カードを**引く**
- カードを手札/山札/捨て札に**加える**
- 山札の一番上に**置く**
- カードを**捨てる**
- カードを**廃棄する**
- カードを**変化させる**
- カードを**アップグレードする**
- コストを支払わずに**プレイできる**

## 7. 片假名政策

- 招式/專有名詞用片假名：ファイアボール、アイスアロー、ライトニングボルト、アイスアーマー、マグヌム・オプス。
- 概念/狀態用漢字：強打、氷河、寒波、神格化、燃焼、冷気、凍結。
- 職業名用片假名：ウィザード（與 アイアンクラッド/サイレント/ディフェクト 一致）。
- 與原版撞名時改名（見 `GLOSSARY.md`）。
- **FORM 系卡名**：原版一律译「〜化」（悪魔化、反響化、死神化、大蛇化、虚無化、死霊化），所以本 Mod 的 Omniscient Form = **全知化**，不要译「全知の形態」。
- **Myth** 取“迷思/误解”义，不译「神話」；jpn 用 **迷妄**。
- **同批卡名去重**：Clear World = **氷結世界**，Purify Sin = **祓罪**，不要让两张都带「浄化」。
- **屬性傷害**：`[orange]炎[/orange]属性のXダメージ`、`[blue]雷[/blue]属性のXダメージ`、`[blue]氷[/blue]属性のXダメージ`（標籤只包屬性詞；`属性のXダメージ` 在外）。

## 8. 事件/對話

- 敘事用 `あなた`，過去時敘事：`〜した。`
- 會話用 `「」`；先古語氣見 `VOICE.md`。
- 舞臺說明用 `[i][font_size=22]…[/font_size][/i]`，句末加半角空格。
- NEOW：古風、`…… ` 停頓；OROBAS：全片假名、無助詞；PAEL：`[thinky_dots]`、〜なさい；TANX：`[b]`、〜ぜ；TEZCATARA：〜のよ/〜わ/〜ねえ；VAKUU：です・ます；ARCHITECT：だ・である、短句。
