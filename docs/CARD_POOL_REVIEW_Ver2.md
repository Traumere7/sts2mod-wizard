### 0.2 ⚠️ 一条方法论警告（上一版没做，这次必须做）

原版描述里夹着 `[gold]…[/gold]` 与 `{Damage:diff()}` 这类标记。
**裸关键词匹配会大面积漏检**——例如"加入你的[gold]手牌[/gold]"，直接搜"加入你的手牌"是 **0 命中**，剥掉标记后是 **13 张**。

> **本文所有原版统计，都是先剥掉 `[tag]` 和 `{变量}` 再匹配的。**
> 上一版若有基于裸匹配得出的结论，都要重算。

## §3.5 ★ 观者 mod 池分析（90 张）—— 抄它的**方法**，不抄它的**机制**

### 3.5.1 机制占用

| 机制 | 张数 | 占池比 |
|---|---|---|
| **姿态（平静 / 愤怒 / 神格）** | **20** | **22%** |
| 格挡 | 21 | 23% |
| **预见 Scry** | **6** | 7% |
| 真言 / 印记 | 5 | 6% |
| 保留 Retain | 5 | 6% |
| 生成/加入手牌 | 4 | 4% |
| **变化 / 复制** | **0** | **0%** |

### 3.5.2 ★★ 值得学的五条（这是本节的重点）

**① 「一个模式，22% 的卡都在读它」**

观者 90 张里 **20 张**和「姿态」有关。这是它**成立**的根本原因：
不是因为它有姿态，而是因为**姿态被全池引用**，于是每张牌的估值都随姿态浮动。

> **对我们「变化」体系的直接启示**：
> Ver.2 初稿只给了 3 张卡——**那是不够的**。
> 一个关键词要"像一个体系"，需要 **15–20% 的卡池在读写它**，
> 按 65 张算就是 **10–13 张**。**这是 §5 需要加码的地方。**

**② 模式必须配「转换器」，不能只有「进入器」**

观者有 `化拳为空 / 化体为空 / 化智为空`——**把当前姿态换成你缺的资源**（伤害/格挡/抽牌）。
没有这三张，姿态就是个只会加成的开关，玩家没有"操作感"。

> **启示**：变化体系必须有一组卡**把"变化"转成法术增益 / 能量 / 抽牌 / 格挡**，
> 而不是只做"变化 → 伤害"。

**③ 让「时间」变成资源：被保留时成长**

`旋转打击`（每次被保留，本场战斗伤害 +N）、`坚韧`（每次被保留，格挡 +N）、`时之沙`（每次被保留，费用 −1）。

> **启示**：巫师是"低费铺场、每回合打很多张"的角色，**手牌流动性极高**——
> 一张"越留越强"的牌在这个角色身上会**特别有张力**：你舍得少打一张吗？
> 而「书签（保留）」已经在池子里，**接口现成**。

**④ 把「序列」当条件：「上一张打出的是攻击/技能牌」**

`粉碎关节`（上一张是技能 → 上易伤）、`追击`、`腰带抽打`、`圣洁`。
**原版 454 张里 0 张**。观者用了 4 张，但**这不是它的招牌**（招牌是姿态）。

> **启示**：这是一个**原版空白、观者轻占**的地。
> 而且它和巫师的主题**天然贴合**——**"咏唱顺序"**。
> ⚠️ 但这是**第三条新轴**，不该和"变化/以太"同时做（见 §7 取舍）。

**⑤ 一张牌可以「按关键词递归」**

`迂回`（每当你预见，把这张从弃牌堆放回手牌）、`疾风连击`（每次转换姿态，回到手牌）。

> **启示**：让某些牌**跟着关键词反复回来**，是提升"体系密度"最便宜的手段——
> 不需要新机制，只需要一张会自我循环的牌。

### 3.5.3 ★ 不要学的地方

| 不学 | 原因 |
|---|---|
| **姿态（三态切换）** | 20 张的体量，是观者的**全部身份**。碰它就是做第二个观者 |
| **预见 / 真言 / 印记** | 同上，观者专属资源 |
| **"抽满手牌"「潦草急就」** | 强到需要单独平衡，且与我们的"低费铺场"叠加会失控 |
| **"额外获得一回合"「腾跃」** | 原版 0 张是有原因的：它破坏回合结构 |

## §5 「变化」体系

### 5.1 巫师其实早就在做"变化"，只是没有名字

| 卡 | 它做的"变化" |
|---|---|
| 幻化 `Transmogrify` | 选 1 张手牌**变化** |
| 泛灵论 `Animism` | **变化**全部手牌（并获得虚无） |
| 迷思 `Myth` | **随机化**所有手牌的耗能 |
| 整理 `TidyUp` | 弃牌堆 → 手牌；手牌 → 抽牌堆顶 |
| 镜像 `Mirror` | 复制全部手牌 |
| 启示 `Inspiration` | 从 3 张随机其他颜色牌里取 1 |
| 暗黑神秘学 `DarkMysticism` | 随机生成攻击/技能/能力各 1 |

> **7 张卡在动"手牌的身份"，但没有任何一张为"动过"这件事付钱。**
> 这和"麻痹/覆甲/格挡只上不给"是同一种病。

### 5.2 ★ 撞车分析（关键，含观者）

| 范围 | "变化"的形式 | "变化"的回报 | "生成"的回报 |
|---|---|---|---|
| **STS2 原版 454 张** | 6（Regent 占 3） | **0** | **1**（超质量体） |
| **观者 mod 90 张** | **0** | **0** | **0** |
| 合计 | 6 | **0** | **1** |

原版唯一吃同类行为的是 **Regent「超质量体」**，而它吃的是 **"生成"（generate）**，不是 **"变化"（transform）**。

> **★ 所以安全区非常明确：**
> **做"变化"的计数回报，而不是"生成"的计数回报。**
> 两者在原版是**分开的动词**——「超质量体」只数"生成"，不数"变化"。
> 我们若数"变化"，**不构成撞车**，而且巫师自己的 7 张卡正好是它的燃料。
>
> **★★ 而"吃变化"这件事，全生态 0 张**（原版 1 张吃的是生成、观者 0 张）。
> 这是本报告里**最干净的一块地**。

### 5.2.1 ⚠️ 但初稿的体量判断错了（借观者的教训）

Ver.2 初稿只给「蜕变」配 3 张卡，写着"够跑起来即可"。对照观者后必须改：

| | 观者 | 巫师（初稿） | 应有 |
|---|---|---|---|
| 核心关键词覆盖 | 姿态 **20/90 = 22%** | 蜕变 **3/65 = 5%** | **15–20% ⇒ 10–13 张** |

> **★ 一个关键词要"像体系"而不是"像彩蛋"，必须被全池反复引用。**
> 3 张卡只会让玩家觉得"这几张牌之间有点关系"，不会觉得"这个角色有一套变化流派"。
> **§5.3 的 3 张只是骨架，验收标准是扩到 10–13 张。**


### 5.3 提案：关键词「蜕变 Metamorph」

> **蜕变**：记录本场战斗中你**变化过**的牌数（transform 计数）。
> 它不是一个挂在敌人身上的状态，而是**角色自己的一条进度条**——类似原版的"本场战斗累计"家族（9 张）。

**示范卡（3 张，够跑起来即可）**

| 卡 | 定位 | 效果草案 | 撞车检查 |
|---|---|---|---|
| **蜕变** `Metamorph` | 罕见 · 能力 · 1 费 | 每当你**变化**一张牌，获得 1 层**法术增益**。 | 原版+观者吃"变化"：0 ✅ |
| **返祖** `Atavism` | 稀有 · 攻击 · 2 费 | 造成 6 点火焰伤害。本场战斗中你每变化过一张牌，就再结算 1 次。 | 段数型，原版同构为「扯碎/谋杀」（吃"失去生命/抽牌"），**吃"变化"的没有** ✅ |
| **炼成** `Transmute` | 普通 · 技能 · 1 费 | 变化你手牌中的 1 张牌。获得 1 层**蜕变**进度。 | ⚠️ 形式上像 Regent「下去！」，**所以必须强调"变化结果不指向固定 Token"**，而是随机牌 |

> **⚠️ 这 3 张是骨架，不是全部。** 按 §5.2.1 的密度要求，还需要 **7–10 张**：
> - **转换器**（借观者"化X为空"）：把"蜕变"进度换成 **能量 / 格挡 / 抽牌**
> - **"留得越久越强"型**（借"旋转打击"）：配合已有的「书签（保留）」
> - **自我递归型**（借"迂回"）：每当变化时回到手牌
> - **反哺型**：让"蜕变"反向影响变化的结果质量（比如变化结果必定升级）


> **★ 与「超质量体」的差异化，一句话**：
> 超质量体数的是**"凭空多出来的牌"**（生成），
> 我们数的是**"已有的牌被改写了"**（变化）——
> **前者的资源是"手牌数量"，后者的资源是"手牌身份"。**

### 5.4 ⚠️ 这个体系的两个风险

1. **可能无限**：如果有"变化 1 张 → 抽 1 张 → 又抽到变化牌"的闭环，会滚。→ **回报必须是"一次性结算"（伤害/费用），不能是"每回合递增的资源"**。
2. **和「全知形态」的耦合**：全知形态吃"每种负面效果"。变化体系若产负面效果，会加速它。→ **变化体系不要产状态**。

## §6 「以太」体系

### 6.1 现状的问题

`design.md` 定义：**法术伤害 = 火焰 + 雷电 + 寒冰**。
而巫师有 **19 张奥术/知识系卡，一张攻击牌都没有**（对照表口径）。
→ **奥术系没有"伤害身份"，只能做辅助。**

### 6.2 ★★ 技术可行性：比预想的便宜得多

我读了 `src/Scripts/Spells/SpellProps.cs`（全文 84 行），发现：

```csharp
[CustomEnum] public static ValueProp Fire;
[CustomEnum] public static ValueProp Lightning;
[CustomEnum] public static ValueProp Ice;

/// <summary>所有法术标记位的合集。</summary>
public static ValueProp All => Fire | Lightning | Ice;   // ★ 已经存在！
```

**伤害类型本来就是 flags 位标记**，而且 **"三种同时亮"的常量已经写好了**。

真正挡住以太的只有一处：

```csharp
public static SpellSchool Resolve(ValueProp props, CardModel? cardSource)
{
    if (props.HasFlag(Fire))      return SpellSchool.Fire;        // ← 第一个命中就返回
    if (props.HasFlag(Lightning)) return SpellSchool.Lightning;   //    把多值塌缩成单值
    if (props.HasFlag(Ice))       return SpellSchool.Ice;
    ...
}
```

> **所以「以太」不是"新增一个伤害类型"，而是"让已有的三个位同时亮"。**
> **数据层已经支持，只有判定层在塌缩。**

### 6.3 需要改的消费点（已定位，共 5 处）

| 文件 | 现在的写法 | 改成 |
|---|---|---|
| `Powers/ChillPower.cs:56-57` | `school != Fire && school != Lightning` | `props.HasFlag(Fire) \|\| props.HasFlag(Lightning)` |
| `Powers/SuperconductPower.cs:96` | `!= SpellSchool.Lightning` | `props.HasFlag(Lightning)` |
| `Powers/CurrentOverflowPower.cs` | 判雷电 | 同上 |
| `Powers/AlternatingCurrentPower.cs` | 判雷电 | 同上 |
| `Relics/TriaPrima.cs`（三原素） | 判三种都造成过 | 同上 |

> **这是"把等值判断换成位判断"的机械替换，不引入新概念。**
> 而且**向后兼容**：普通伤害仍然只带一个位。
> ⚠️ 具体实现属工程，**我只是把范围量出来**——按边界我不动代码。

### 6.4 ★★★ 配平铁律：以太会被自己的规则反噬

因为以太**同时是火焰+雷电+寒冰**，它会**同时吃到**：

| 乘区 | 为什么 |
|---|---|
| 法术增益 | 是法术伤害 ✅ |
| 易伤 | 是法术伤害 ✅ |
| **寒冷 +50%** | 寒冷 buff"火焰和雷电" → 以太两者都是 ✅ |
| **超导 +50/75%** | 超导 buff"对寒冷敌人的雷电" → 以太是雷电 ✅ |

> **= 4 个乘区，和雷电完全同档。**
>
> 而你在回执 §6.1「刻度二」里定的规则是：
> **"吃最多乘区的学派，面板数值要最克制"**（所以雷光 2 费只有 8(10)）。
>
> ⇒ **以太的伤害面板必须 ≤ 雷电，也就是三系里最低。**

**这带来一个现实问题**：一张 2 费的以太攻击如果只有 6–8 点，**手感会很差**。
所以我的建议是：

> **★ 以太不做"高伤害属性"，做"判定通配符"。**
> 以太牌的**伤害数值给得很小**，它的价值在于**同时满足三系的判定**：
> 触发超导、满足"造成过寒冰"、给电流外溢计数、满足三原素的"三系都打中过"。
> **它是钥匙，不是锤子。**

### 6.5 三条不可越的红线

| # | 红线 | 原因 |
|---|---|---|
| **1** | **以太伤害面板必须 ≤ 雷电** | 乘区与雷电同档（§6.4） |
| **2** | **以太不自动施加三种状态** | 否则一击就满足「全知形态」的"本回合新种类"和「纵火狂」的"给予燃烧"，直接崩 |
| **3** | **以太只出现在稀有 / 先古** | 它是"不受学派限制"的特权，做成普通卡会让三系身份失去意义 |

### 6.6 示范卡（3 张）

| 卡 | 定位 | 效果草案 |
|---|---|---|
| **以太箭** `AetherBolt` | 稀有 · 攻击 · 1 费 | 造成 **4(6)** 点**以太伤害**（同时视作火焰/雷电/寒冰）。 |
| **原质** `PrimaMateria` | 稀有 · 能力 · 2 费 | 你的以太伤害**额外**视作"已给予过"的学派（即：以太牌也计入"本回合造成过火焰/雷电/寒冰"的判定）。 |
| **万有** `Plenum` | 先古 · 攻击 · 3 费 | 对全体造成 **7(10)** 点以太伤害。若你本回合已造成过火焰、雷电、寒冰三种伤害，改为 **14(20)**。 |

> **注意第 3 张**：它**主动要求你先打三系**，才翻倍——
> 这保证了"以太"不会取代三系，而是**三系体系的终点**。
> 这也是给已有的「三原素」遗物（同回合打三种 → 无实体）做**剧情呼应**。
